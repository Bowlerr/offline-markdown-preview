# Branding assets

The 0.5.1 icon was created with the built-in image generation tool from the maintainer's supplied Markdown-and-page reference. The master PNG retains the generated image’s exact pixels and transparency after lossless compression. Version 0.5.4 exports a uniformly scaled 1024-pixel store icon to meet Marketplace limits; the banner continues to use the original master. After generated banners redrew the mark, the maintainer explicitly requested exact-pixel reuse, a soft text shadow, and a rounded app-tile border with a shadow. The final banner is composed locally with Sharp from this exact icon plus real text; see `scripts/build-banner.cjs`. The icon is uniformly scaled once and composited without redrawing. A fine blue border follows the source tile's alpha silhouette, with a soft shadow behind the tile. A separate low-opacity, 2-pixel blur shadow is applied to the two title lines.

- `images/icon-master.png`: original approved pixels; used for the banner and excluded from the VSIX.
- `images/icon.png`: 1024-pixel store icon, rebuilt with `scripts/build-icon.cjs`; checked at small display sizes on light and dark backgrounds.
- `images/banner.png`: README and registry header; the product name is also provided as accessible text in the README.
- `images/preview.png`: direct, unedited screenshot of the installed 0.5.1 package in an isolated VS Code 1.110.1 profile. The public Project notes example shows Mermaid, math and highlighted code; no private documents or account information appear.
- Marketplace header color: `#092549`, matched to the SQLite IntelliView companion banner at the maintainer's request.
- Final banner eyebrow: `LOCAL · OFFLINE · FREE`. The right side contains a full-height rendered Markdown preview illustration that fades toward the title, following the latest companion design. The illustrative preview includes headings, a checklist, a diagram, math and code. The fade was strengthened at the maintainer's request, with a smooth transition and no hard left edge. The supported-editors table remains in the README with direct test coverage and compatibility requirements.

## Final icon prompt

Use case: logo-brand. Create the final production app icon for the Offline Markdown Preview VS Code extension, using the attached image as the design reference. Preserve its core design: a dark navy rounded-square tile; a unified open-book/two-page symbol centered inside; left page electric blue with a bold white uppercase M; right page white framed in cyan with two navy horizontal rounded strokes and one shorter cyan stroke. Refine only optical balance and crisp geometry for excellent readability at 32, 64 and 128 pixels. Very clean flat vector-like shapes, no grain, no 3D, no glow, no cast shadow, no extra decoration. Use deep navy #06234A, electric blue #087CFA, cyan #00C5E9, white. Square 1024x1024 composition, tile occupies roughly 94% of canvas, generous but compact padding within tile, balanced equal-width left and right pages, clear M shape, centered. Transparent pixels outside rounded tile, preserve an opaque navy tile. Only text is the single uppercase M. Do not add the product name, border, mockup, labels or watermark. Deliver a single finished icon, not a presentation sheet.
